# Темы докладов

1. Математические основы жадных алгоритмов: теория матроидов и условия гарантии глобальной оптимальности.
2. Динамическое программирование в биоинформатике: алгоритм Нидлмана — Вунша для выравнивания биологических последовательностей.
3. Метод ветвей и границ как развитие метода полного перебора для задач целочисленного линейного программирования.
4. Метаэвристические алгоритмы оптимизации: генетические алгоритмы, имитация отжига и метод муравьиной колонии.
5. Алгоритм Карацубы и алгоритм Шёнхаге — Штрассена: применение метода «разделяй и властвуй» для умножения больших чисел.
